# JS MXMP Editor

**JS MXMP Editor** — это легковесный, быстрый и адаптированный под мобильные устройства веб-редактор кода на JavaScript. Проект построен на базе современного движка **CodeMirror 6** и сборщика **Vite**, что обеспечивает мгновенную загрузку и плавную работу даже на смартфонах.

## Основные возможности

* **Адаптивный интерфейс:** интерфейс оптимизирован для работы на мобильных экранах, включая увеличенный размер шрифта (16px) для предотвращения нежелательного зума браузера при фокусе на коде.
* **Продвинутое автодополнение:** кастомный источник подсказок сканирует глобальную область видимости (`globalThis`) и выводит функции, объекты и переменные со специальными иконками прямо во время ввода.
* **Управление файлами:** полноценный сайдбар для создания и удаления `.js` файлов с защитой от удаления главного файла `main.js`.
* **Автосохранение:** встроенный слушатель изменений автоматически сохраняет код в локальное хранилище при каждом редактировании.
* **Интегрированная консоль:** запуск JS-кода в один клик с перехватом методов `console.log`, `console.warn`, `console.error` и выводом форматированного результата (включая JSON-объекты) прямо на экран.
* **Красивое оформление:** тема *One Dark* и поддержка моноширинных шрифтов (*JetBrains Mono*, *Fira Code*).

## Технологический стек

* **Сборщик:** Vite 8
* **Ядро редактора:** CodeMirror 6 (модули `@codemirror/state`, `@codemirror/view`, `@codemirror/autocomplete`)
* **Языковой пакет:** `@codemirror/lang-javascript`
* **Тема:** `@codemirror/theme-one-dark`

## Быстрый старт

### Требования
Для запуска проекта вам понадобится установленная среда **Node.js**.

### Установка зависимостей
Склонируйте репозиторий и установите пакеты:
```bash
npm install
```

### Запуск в режиме разработки
Запуск локального сервера с флагом `--host` для удобного тестирования с мобильного телефона в одной Wi-Fi сети:
```bash
npm run dev
```
После запуска откройте в браузере смартфона указанный в терминале IP-адрес.

### Сборка для продакшена
Компиляция проекта в оптимизированные статические файлы:
```bash
npm run build
```

## Структура ключевых файлов проекта

* `index.html` — основная разметка приложения (редактор, сайдбар файлов, диалоговое окно и консоль).
* `main.js` — инициализация CodeMirror, настройка кастомного автодополнения, логика работы с DOM и перехват консоли.
* `storage.js` — модуль для работы с `localStorage` (сохранение, чтение и удаление файлов).
* `package.json` — конфигурация скриптов и список зависимостей.
